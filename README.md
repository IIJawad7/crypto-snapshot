# crypto-snapshot

يسحب بيانات العملة والأخبار تلقائيًا، ويحفظها في تقرير واحد (`reports/latest.md`) يقدر Claude يقرأه.

- **للقراءة فقط:** يستخدم بيانات Binance العامة. ما يحتاج مفاتيح API، وما يقدر يشتري أو يبيع.
- **بدون مكتبات:** Python فقط، ما يحتاج `pip install`.

## وش يطلع في التقرير

- السعر، والتغير خلال ٢٤ ساعة و٧ أيام و٣٠ يوم
- MA7 / MA25 / MA99، وRSI على اليومي و٤ ساعات
- متوسط الحركة اليومية (ATR) والتذبذب
- حجم التداول مقارنة بمتوسط ٢٠ يوم
- أعلى وأقل سعر خلال ٣٠ و٩٠ يوم
- المسافة بين السعر الحالي ومستوياتك (الدخول والهدف والخسارة)
- حالة BTC، ومؤشر الخوف والطمع (Fear & Greed)
- أخبار آخر ٤٨ ساعة من CoinDesk وCointelegraph وDecrypt وThe Block وGoogle News

## التشغيل

- من تبويب **Actions** اختر **Crypto snapshot** واضغط **Run workflow**. تقدر تسويها من تطبيق GitHub في الجوال بعد.
- فيه تشغيل تلقائي كل يوم الساعة ٧:٤٧ الصبح بتوقيت الرياض.
- التقرير يتحدث على هذا الرابط:
  `https://raw.githubusercontent.com/IIJawad7/crypto-snapshot/main/reports/latest.md`

## التعديل

كل الإعدادات في `config.json`:

- `levels`: مستوياتك (`entry` و`target` و`stop`). حدّثها كل ما تغيرت خطتك.
- `coins`: تقدر تضيف عملة ثانية بنفس الشكل، مثل `"symbol": "SOL"`.
- `news_keywords`: الكلمات اللي يبحث عنها في الأخبار.

## ملاحظات

- **لا تحط أي مفتاح API من Binance في هذا المستودع.** السكربت ما يحتاجه أصلًا.
- إذا تعطل مصدر أخبار معين، يكمل السكربت ويسجل الخطأ في آخر التقرير.
- رابط raw على GitHub ممكن يتأخر كم دقيقة قبل ما يعرض آخر نسخة.
- تجربة محلية: `python snapshot.py`
